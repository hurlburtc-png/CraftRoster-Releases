## Installing

1. Open this repository's **Releases** page and download the latest verified `CraftRoster.zip` asset. Do not use GitHub's automatically generated source ZIP.
2. Extract into the WoW Forever game's `Interface/AddOns` directory.
3. Confirm the layout is `Interface/AddOns/CraftRoster/CraftRoster.toc` (no extra nested CraftRoster directory).
4. Restart or reload the game and enable CraftRoster in the addon list.

## Version and integrity

Each published release should contain: the exact beta version and release time, `CraftRoster.zip`, a SHA-256 checksum, concise release notes, and corresponding source code or a source archive. A GitHub autogenerated source archive is **not** the install ZIP.

## Safety

CraftRoster does not automatically accept trades or guarantee delivery of messages to offline players. The player must confirm the final trade. Beta automated tests simulate Forever APIs and do not replace in-game validation.

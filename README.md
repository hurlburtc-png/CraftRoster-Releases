## Installation

1. Download **CraftRoster.zip** from the linked release. Do **not** download GitHub's autogenerated **Source code (zip)**.
2. Extract the ZIP into your WoW Forever installation's `Interface/AddOns` folder.
3. Verify this exact layout: `Interface/AddOns/CraftRoster/CraftRoster.toc`. There should be only **one** CraftRoster folder, not `CraftRoster/CraftRoster/CraftRoster.toc`.
4. Restart the game, enable CraftRoster in the addon list, and open it in game.

## What it does

- Search guild members and recipes, including known crafters and profession information.
- Inspect recipe ingredients, sources and available cost estimates.
- Build shopping lists and multi-recipe crafting projects.
- Draft crafting requests and coordinate external crafters who do not have the addon.
- Review material quantities for trade and mail. **The player must always manually accept the final trade.**
